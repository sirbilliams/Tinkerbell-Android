# Tinker Bell for Android

A faithful reconstruction of *Disney's You Can Fly! with Tinker Bell* (PC, 2002), rebuilt from the retail
executable to run natively on Android (made for the AYN Thor). Work in progress.

This repository contains no game files. The app installs the game from your own copy of the CD (an ISO
image of it), and reads the values it needs from your copy of the game's executable at run time.
